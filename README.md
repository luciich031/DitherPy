# DitherPy
Customize your images with a dithering effect. Built with Python, just launch the script, load the image, configure and save!


# Dithering Tool

A dithering application built with **PyQt5** and **Pillow**.

## Features

- Retro UI
- Floyd-Steinberg method
- Image Display
- Status bar
- Color depth options (2, 4, 8, 16, 32, 64, 128 and 256)
- MORE TO BE ADDED LATER ON!!

## Requirements

- Python 3.x
- PyQt5
- Pillow

## Installation

```bash
# Clone the repo
git clone https://github.com/YOUR_USERNAME/dithering-tool.git
cd dithering-tool

# Create a virtual environment (recommended)
python -m venv venv
source venv/bin/activate

# Install dependencies
pip install PyQt5 Pillow
